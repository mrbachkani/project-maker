# Component Library

This folder contains reusable React components that can be imported into projects generated by the Project Maker.  Each component is designed to be minimal and easily styled with Tailwind CSS.  Before creating a new component, check if the functionality already exists here.

## Components

- **Card.jsx** – A simple container with an optional title and content area.
- **DataTable.jsx** – Renders tabular data given an array of column definitions and data objects.
- **AuthForm.jsx** – A login form that collects email and password; you can attach your own submit handler via the `onSubmit` prop.

Feel free to extend this library as you identify patterns that can be shared across projects.  If you add a new component, update this README to describe its purpose.
